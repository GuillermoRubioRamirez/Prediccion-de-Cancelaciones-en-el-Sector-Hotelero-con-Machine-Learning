## Predicción y reducción de cancelaciones de reservas hoteleras

Proyecto desarrollado en colaboración con Líbere Hospitality Group para reducir el impacto económico de las cancelaciones de reservas en el sector turístico.

A partir de datos reales de más de 40.000 reservas, se desarrolló un modelo predictivo capaz de anticipar cancelaciones utilizando técnicas de aprendizaje automático como regresión logística y máquinas de vectores de soporte (SVM), combinadas con métodos de balanceo de clases (SMOTE, ADASYN y Cluster Centroids) para tratar el desequilibrio entre reservas canceladas y no canceladas.

Se integró información meteorológica mediante las APIs de AEMET, analizando su impacto en el comportamiento del cliente y la probabilidad de cancelación. Adicionalmente, se realizó scraping de opiniones de usuarios en Booking, identificando fortalezas (ubicación, limpieza) y debilidades (sofás cama, colchones) del servicio, lo que permitió diseñar estrategias concretas de mejora de experiencia y fidelización.

Para el seguimiento del negocio, se construyó un dashboard interactivo en Kibana que permite monitorizar tendencias meteorológicas y de reservas. Finalmente, se elaboró un plan de acción integral con estrategias de marketing, fidelización, mejoras operativas y feedback continuo, con el objetivo de reducir las cancelaciones en un 15% en un plazo de seis meses.
